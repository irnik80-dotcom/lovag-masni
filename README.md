# Lovag & Masni – A fonal kalandja

Kétszemélyes, böngészős platformjáték: egy nagy lovag és egy masnis cica, egy piros fonallal összekötve. Amiga/C64 stílusú chiptune zenével.

**Játék:** https://irnik80-dotcom.github.io/lovag-masni/

- Egy eszközön ketten (billentyűzet, érintés vagy két kontroller)
- Online két telefonon: az egyik szobát nyit, a másik a 4 jegyű kóddal vagy a meghívó linkkel csatlakozik
- 4 pálya: Virágos rét, Kristálybarlang, Felhőkastély, Randevú holdfénynél (18+ 😉)
- Xbox-kontroller: A ugrás, B horgony, X kard/miaú, Start szünet

A telefonok közti kapcsolat [PeerJS](https://peerjs.com/) segítségével megy (peerjs.min.js, MIT licenc).
